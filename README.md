# DEER Guess Lab

An interactive phase-plane tool for building intuition on how the initial guess shapes the convergence of
DEER and quasi-DEER (parallel Newton solvers for ODE trajectories).

**Live page:** https://emmiefitzgibbon.github.io/deer-guess-lab/

You can draw or pick initial guesses on 2-D systems and watch the Newton iterations converge or fail. Pretrained
MLP guesses are included.

The page is a single self-contained HTML file. Everything runs as plain JavaScript in your browser, with no server
and no dependencies. To use it offline, download `index.html` and open it.
